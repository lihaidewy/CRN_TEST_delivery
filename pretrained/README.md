# 初始化权重

本交付包包含 `s3_full_512h_epoch23_step13392.ckpt`，用于新场景微调初始化。
它来自 S3 仿真场景，使用 BEV `[0,192]×[-40,40] m`、0.4 m 网格及 512×1408
模型图像输入。指标是训练集评估结果，不代表外场精度保证。

已记录的训练集评估：S3M 211 帧、阈值 0.5 时 MOTA=99.50%、2D ATE=0.250 m、P90=0.512 m；
S3M+S3S 共 558 帧、阈值 0.6 时 MOTA=98.47%、2D ATE=0.284 m、P90=0.579 m。
两组均为训练集内评估，不是独立测试结果。

配置驱动的场景通过 `training.init_checkpoint` 指向该文件；从头训练时设为 `null`。
固定 S3 脚本可通过 `CRN_S3_INIT_CKPT` 环境变量指定。文件约 705 MiB。
