# CRN 网络架构与方法说明

> 本文用于向新的对话或项目协作者介绍 CRN（Camera-Radar Network）的基本思路和网络架构。本文只说明方法，不绑定某个具体场景、数据集划分、训练配置或代码文件。不同实验可能会调整骨干网络、网格尺寸、损失权重或可选模块，使用时应以对应实验设置为准。

## 一、CRN 要解决什么问题

CRN 是一个相机与雷达融合的三维目标检测方法。相机图像提供丰富的外观、纹理和类别线索，但单目图像缺乏直接的距离信息；雷达能够提供稀疏的空间测量和运动相关信息，但点数少、语义信息有限。CRN 希望利用两种传感器的互补性，在统一的鸟瞰视角（Bird's-Eye View，BEV）中融合特征，并输出目标的三维边界框。

它不是将原始图像和雷达表格直接拼接，而是大致遵循以下流程：

```text
相机图像 → 图像特征提取 → 深度分布估计 → 几何视角变换 ─┐
                                                        ├→ BEV 多模态融合 → 3D 检测头 → 目标框
雷达点   → 点/柱状体特征编码 → 雷达空间特征 ───────────┘
```

## 二、输入与几何信息

网络的主要输入包括相机图像和雷达点。将图像特征转换到 BEV 时，还需要相机内参、相机与场景坐标系之间的外参，以及图像缩放、裁剪等增强操作对应的几何变换。

这些标定信息的作用是建立几何对应关系：图像中的位置和某个深度假设对应场景空间中的哪个位置，以及该位置应落入哪个 BEV 网格。标定矩阵本身不是神经网络学习出的视觉特征；它为视角变换提供坐标依据。几何信息有误时，图像特征可能被放到错误的 BEV 位置，进而影响融合和检测。

## 三、图像分支

### 3.1 图像骨干与多尺度特征

图像先经过卷积神经网络骨干提取特征。随着网络层数加深，特征由边缘、纹理等低层信息逐渐变为形状和类别等高层语义信息。特征金字塔网络（Feature Pyramid Network，FPN）再融合不同分辨率的特征，使网络兼顾细节和语义，并适应不同尺寸的目标。

这一步的输出仍处于图像平面坐标中，并没有直接成为 BEV 特征。

### 3.2 深度分布估计

图像分支会为图像特征预测一组离散深度区间上的概率。对于某个图像位置，网络不是简单地指定唯一距离，而是表示它落在不同深度区间的可能性。

设图像上下文特征为 \(F(u,v)\)，离散深度区间为 \(d_k\)，对应概率为 \(p(d_k\mid u,v)\)。视角变换会把特征按深度概率分配到空间位置，可概念化写作：

\[
F_{3D}(u,v,d_k)=p(d_k\mid u,v)\,F(u,v).
\]

这是 LSS（Lift-Splat-Shoot）类方法的核心直觉：先将图像特征沿可能的深度方向“抬升”（Lift），再依据几何关系投到空间网格并聚合（Splat）。

### 3.3 从相机视角变换到 BEV

深度加权后的图像特征结合相机内参和相机到场景坐标系的外参，映射到三维空间；随后按 BEV 网格汇聚，形成鸟瞰特征图。实现中通常会过滤无效空间位置，并将同一网格内的特征进行池化。

因此，图像到 BEV 的转换同时依赖两部分：

1. 网络预测的深度概率，决定图像特征沿深度方向如何分配；
2. 标定和坐标变换，决定这些候选空间位置在场景坐标中的实际落点。

## 四、雷达分支

雷达点是稀疏且不规则的，不能像图像像素一样直接用二维卷积处理。CRN 使用点云编码思路，将点划分到空间单元中，再把单元内的点汇聚成特征。

典型处理过程如下：

1. 对雷达点进行体素化或柱状化；
2. 用 PointPillars 风格的特征网络编码每个单元中的点及其测量属性；
3. 将稀疏单元特征散射回规则特征图；
4. 使用卷积骨干和特征金字塔提取更高层雷达特征。

雷达分支可以输出两种互补信息：

- **雷达上下文特征**：编码有观测位置处的雷达点及其属性；
- **占用/可见性提示**：表达空间位置是否有雷达观测或相应的占用概率。

雷达的优势是提供直接的距离、方位或运动测量线索；其局限是点稀疏、目标语义弱，而且测量质量可能随距离、遮挡和反射条件变化。雷达特征的实际通道含义取决于数据预处理所提供的点特征，不应脱离具体数据格式假设固定列顺序。

## 五、雷达辅助的图像视角变换

CRN 的雷达信息不只在最终融合时才出现。在启用相应的雷达视角变换路径时，雷达占用提示还会与图像上下文结合，辅助图像特征的空间聚合。直观地说，雷达观测可以为“哪些位置存在空间证据”提供提示，帮助图像特征建立更合适的空间表示。

需要区分“雷达参与网络”和“显式雷达深度监督”：前者指雷达特征在前向过程中帮助图像特征变换或参与 BEV 融合；后者是训练时额外拿雷达距离标签监督深度预测。网络可以使用雷达特征，但某个实验仍可能关闭显式雷达深度损失。

## 六、多模态 BEV 融合

图像和雷达特征进入融合模块时，已被整理到 BEV 表示中。融合模块先对不同模态特征进行归一化和维度映射，再通过多模态特征聚合（MFA）融合信息。其关键方法是**可变形交叉注意力**，思想与 Deformable DETR 一类方法相关。

对每个 BEV 查询位置，注意力模块会学习：

- 从图像特征图和雷达特征图中的哪些位置采样；
- 不同采样位置、不同模态应分配多大权重；
- 如何将采样信息组合成更新后的 BEV 特征。

可变形注意力不像密集全局注意力那样让每个位置都与所有特征位置交互，而是学习少量相关采样点，有助于把计算集中在当前 BEV 位置需要的信息上。融合层通常还包含位置编码、前馈网络、归一化和残差式特征更新。

## 七、BEV 检测头

融合后的 BEV 特征进入卷积骨干和特征金字塔，再由检测头预测三维目标。检测头采用 CenterPoint 风格的中心点检测思路：先预测目标中心热图，再在中心位置回归目标框属性。

常见预测量包括：

| 预测分支 | 含义 |
|---|---|
| 中心热图 | 哪些 BEV 位置可能是目标中心，以及对应类别置信度 |
| 中心偏移 | 连续目标中心相对于离散 BEV 网格中心的偏移 |
| 高度 | 目标中心或框在垂直方向的位置 |
| 尺寸 | 目标的长、宽、高 |
| 航向 | 目标朝向，常用正弦和余弦等形式回归角度 |
| 速度 | 目标在平面上的速度分量（若任务配置启用） |

推理时，检测头从中心热图中筛选候选峰值，解码对应的框属性，再经过分数筛选和非极大值抑制等后处理，得到最终的逐帧三维检测结果。

## 八、训练目标

训练时，预测结果与三维框标注进行比较。常见的损失包括：

1. **中心热图损失**：监督目标中心和类别响应，常用高斯焦点损失。真实中心附近可通过高斯目标提供平滑监督。
2. **框回归损失**：监督中心偏移、高度、尺寸、航向和速度等，常用 L1 类回归损失。
3. **可选辅助损失**：例如深度监督、邻格回归或中心峰值排序等。它们是否启用、如何加权由具体实验方案决定，并非 CRN 必然始终启用的组成部分。

模型通过这些监督共同学习图像特征、雷达特征、BEV 映射、跨模态融合和检测输出。检测损失可以通过网络反向传播影响前面的可学习模块；几何标定矩阵则提供坐标变换关系。

## 九、训练与推理的区别

- **训练阶段**：输入图像、雷达数据和标注框，计算中心热图及框回归等损失，并通过反向传播更新网络参数。
- **推理阶段**：只输入图像、雷达数据及必要的标定信息，输出逐帧检测框、类别和置信度，不使用真实标注计算训练损失。
- **跟踪阶段**：若系统需要跨帧 ID 或轨迹，通常在检测结果之后由独立跟踪模块完成；跟踪不等同于 CRN 的单帧检测头。

## 十、方法总结

CRN 的方法链条可以压缩为：

1. 用卷积骨干和 FPN 提取图像多尺度特征；
2. 预测图像特征的离散深度分布；
3. 依据标定关系将图像特征从相机视角投影到 BEV；
4. 用 PointPillars 风格网络将稀疏雷达点编码为特征和空间提示；
5. 用雷达辅助视角变换及可变形交叉注意力融合图像与雷达 BEV 特征；
6. 用 CenterPoint 风格检测头输出三维目标中心、尺寸、航向及其他属性。

最核心的设计思想是：**相机提供丰富语义，雷达提供稀疏空间测量；两者通过几何变换进入共同的 BEV 表示，再由注意力机制学习互补信息，最终完成三维检测。**
